# CS11 蓝牙音乐（1.1.0-rc.1）

此模式用于**手机通过蓝牙向 CS11 车机播放音乐**，不要求手机安装云途。

1. 在原车蓝牙设置中配对并连接手机，确认开启“媒体音频”。
2. 云途“当前播放”页顶部点击“音源”，选择“蓝牙音乐 · 手机播放到车机”。
3. 点击播放，或在手机播放器中开始播放。支持播放/暂停、上一首/下一首；实际能力取决于手机播放器和车机固件。
4. 收到歌曲信息和进度后显示在播放页、通知和悬浮卡片中。悬浮窗继续使用现有的字号、颜色、位置和权限设置。
5. 切回网易云保留原队列，点击播放继续；从网易云歌单或搜索结果点歌也会切回网易云。蓝牙播放列表、喜欢、收藏、播放顺序和拖动进度不做假映射，请在手机操作。

音源选择会保存。如果启用了启动后自动播放，蓝牙模式会最多等待手机连接 60 秒，然后发送一次播放指令；不会主动开启蓝牙、配对或重连手机。手动操作会取消等待。

## 歌词

检查过的 CS11 ECARX 接口只有歌名、歌手、专辑、时长和进度，没有独立歌词字段。

部分手机播放器能把当前歌词作为蓝牙歌名发送。如果手机播放器提供该功能，先在手机端开启，然后在云途“设置 → 播放设置”启用“蓝牙歌名作为歌词显示”并保存。

- 开启后按收到的文本显示，云途无法判断普通歌名和单句歌词；手机没有开启相应发送功能时会显示歌名。
- 仅收到当前句时只显示当前句，不推测或联网匹配下一句。歌名区域也会显示手机实际传来的内容。
- 收到带时间戳的 LRC 文本时可按手机报告的进度展示多行歌词。
- 没有歌词时播放页/卡片显示提示；纯悬浮歌词为空，不占用额外触摸区域。
- 断连、切歌事件和切换音源会清除旧歌词；蓝牙内容不会发送到网易云搜索/歌词/喜欢接口。

## 兼容范围与诊断

API 19 上播放指令优先通过原车媒体服务的 `CUSTOM_PLAY_BT_ACTION` 选择蓝牙音源，由原车管理焦点、方控和仪表盘。接口不可用时退回直接 AVRCP 控制；如被原车其他音源打断，请先在原车播放器选择蓝牙。原车播放器存在时，云途不争抢音频焦点。**原车播放器已经删除或停用时无需重装**：云途直接使用底层蓝牙接收服务，并自行申请音频焦点、注册方控和发布仪表盘信息；导航请求临时音频焦点时暂停，恢复焦点后继续播放。底层 `ecarx.bluetooth.service` 必须保留。

使用原车 `ecarx.bluetooth.service/.a2dp.A2dpService` 和 `ecarx.bluetooth.IBluetoothA2dp` 的 CS11 接收端协议。无车机服务的普通手机/模拟器会显示不支持提示，不会变成蓝牙音频接收器。不安装、修改或打包原车 APK/SDK。仅保留一个 API 19 `MediaSessionCompat.Token` 的 Parcelable 同名协议载体供解析原车返回值，不包含 support SDK 实现。

所有 Binder 通信使用一个串行后台线程，限制轮询为每两秒一次；连接或查询响应超时会显示提示。断连/服务重建会清除旧状态，关闭时注销回调和解除绑定。手机地址、歌曲/歌词正文不进入诊断日志。

```sh
adb logcat -v threadtime -s YuntuBluetooth:V YuntuPlayback:I AndroidRuntime:E
```

协议依据：用户提供的 `多媒体XCMedia2.apk` 中客户端，以及本地 CS11 原车蓝牙服务的 AIDL/Parcel 契约。这里只实现互操作所需字段和事务，不包含反编译的厂家实现。事务号：3 已连接设备、8 播放状态、9 控制、10 AVRCP 就绪、11/12 请求信息/进度、13 通话占用、14/15 注册/注销回调、16/17 接收音频开关；不调用连接、断连和配对接口。

`BluetoothTest` 使用隔离 Binder fixture 验证编码、状态、歌词与音源切换。**还需要 CS11 实测**：实际出声、手机播放器指令响应、方控、仪表盘、导航/通话音频共存、冷启动和长时间播放。模拟器测试不能证明这些 OEM 行为已经正常。
