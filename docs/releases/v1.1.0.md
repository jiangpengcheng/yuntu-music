云途音乐新增 CS11 蓝牙音乐音源，让已连接的手机向车机播放音乐，并显示收到的歌曲信息及歌词。`1.1.0-rc.1` 已由用户确认测试通过。

- 在“当前播放 → 音源”切换网易云与蓝牙音乐，支持播放/暂停、上一首/下一首；切回网易云保留原队列。
- 原车多媒体播放器已删除时无需重装：云途直接使用底层蓝牙服务，并管理音频焦点、媒体键和仪表盘信息。原车播放器存在时优先使用其蓝牙音源切换接口，避免互相抢占焦点。底层 `ecarx.bluetooth.service` 必须保留。
- 收到的歌曲信息显示在播放页、通知及悬浮卡片中。可在“设置 → 播放设置”开启“蓝牙歌名作为歌词显示”，用于手机播放器将歌词通过蓝牙歌名发送的模式；需在手机端开启相应功能。仅收到当前句时只显示当前句，收到带时间戳的 LRC 文本时按进度显示。
- 蓝牙模式支持等待已有手机连接后自动播放，不会主动开启蓝牙、配对或重连手机；手动操作会取消自动播放等待。
- 厂商接口在后台串行处理，增加超时提示、断连恢复和过期回调隔离，避免蓝牙服务响应慢时阻塞界面。

下载 `yuntu-music-1.1.0.apk` 安装。包名仍为 `io.github.yuntumusic.direct`，内部版本号为 7，沿用现有签名，可覆盖升级 `v1.0.0` 和 `1.1.0-rc.1`，保留登录、队列及设置。使用 `SHA256SUMS.txt` 校验下载文件。

继续兼容 Android 4.4 / API 19。6 项主机测试和 10 组、341 项离线模拟器检查通过，其中 52 项覆盖蓝牙协议、无原车播放器控制、自动播放、歌词悬浮、焦点及故障恢复。实际歌词和控制能力取决于手机播放器及车机固件，不保证所有机型支持；蓝牙接口没有独立歌词字段，不会联网猜测歌词。
