云途音乐首个正式开源版本，基于已经过 CS11 测试的原生直连方案。

- Android 4.4 / API 19 起，无需外部 API 服务；原生 Java 界面与接口。
- 扫码登录，歌曲/歌手/专辑/歌单搜索，完整歌单、私人 FM、音质选择、喜欢与收藏。
- 系统媒体键与方控、通知控制、仪表盘播放进度、无音源自动下一首。
- 普通悬浮卡片、等宽三行大号卡片、两行交替悬浮歌词；字号与当前/下一句颜色可设置。
- 悬浮歌词全透明、居中且按文字宽度自适应，窗口外可操作下层应用；按住直接拖动，点击返回。
- 可选开机自启和恢复上次队列自动播放。
- 整理独立源码仓库、固定依赖校验、离线模拟器回归与自动签名发布 workflow。

下载 `yuntu-music-1.0.0.apk` 安装。包名 `io.github.yuntumusic.direct`，沿用 native 测试版签名，可直接覆盖升级；与旧网关版独立共存。可使用 `SHA256SUMS.txt` 验证文件。

构建严格使用 Android 19 SDK / Java 7，APK 包含 v1/v2 签名和 DEX 035。自动测试使用合成数据，不需要网易云账号。真实车机行为以具体固件为准；之前 native 测试版的实测不代表全部车型验证。本项目为独立客户端，曲目可用性仍取决于账号和授权。
